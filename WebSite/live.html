Mode live

Essayez Voktora sans l'installer : une commande, tout est utilisable, et tout est supprimé à la fermeture.

Lancer

linux, macOS — sh
curl -fsSL https://raw.githubusercontent.com/yo-le-zz/Voktora/main/Installers/live/install-live.sh | sh
windows — powershell (non testé)
irm https://raw.githubusercontent.com/yo-le-zz/Voktora/main/Installers/live/install-live.ps1 | iex

Prérequis : curl et tar (Linux/macOS), accès à GitHub, et les bibliothèques système de Qt. Python 3.13 et les dépendances sont préparés dans le dossier temporaire par uv, installé lui aussi dans ce dossier s'il est absent. Première exécution : 1 à 2 minutes.

Ce qui se passe

  • Un dossier privé voktora-live-XXXXXXXX est créé dans le dossier temporaire du système ; rien n'est écrit dans votre dossier personnel.
  • Code, Python, dépendances, configuration, plugins, thèmes, coffre et projets créés vivent dans ce dossier.
  • À la fermeture, Voktora propose d'exporter vos projets, puis supprime tout. Le script supprime aussi le code et l'environnement, même après Ctrl+C ou fermeture du terminal.
  • Synchronisation entre PC, mise à jour automatique et moniteur développeur sont désactivés : rien ne doit survivre.

Options

VariableEffet
VOKTORA_LIVE_REF=v1.1.6version à lancer (étiquette ou branche) ; par défaut la dernière release, sinon main
VOKTORA_LIVE_KEEP=1débogage : ne rien supprimer à la fin

Limites

  • Le code vient de l'archive GitHub de la version demandée, sans somme de contrôle (HTTPS seulement). Relisez le script avant de l'exécuter.
  • Une coupure brutale (kill -9, extinction) peut laisser le dossier temporaire ; il est nettoyé au lancement suivant ou au redémarrage du système.
  • La suppression est un effacement de fichiers, pas un effacement sécurisé.
