Debian, Ubuntu, Mint

Recommandé sur ces distributions. Fichier : voktora_1.1.5_amd64.deb

deb — sh
wget https://github.com/yo-le-zz/Voktora/releases/latest/download/voktora_1.1.5_amd64.deb
sudo apt install ./voktora_1.1.5_amd64.deb   # résout aussi les dépendances
voktora

# désinstaller
sudo dpkg -r voktora

Fedora, RHEL, openSUSE

Les bibliothèques Qt sont résolues automatiquement. Fichier : voktora-1.1.5-1.x86_64.rpm

rpm — sh
wget https://github.com/yo-le-zz/Voktora/releases/latest/download/voktora-1.1.5-1.x86_64.rpm
sudo dnf install ./voktora-1.1.5-1.x86_64.rpm      # Fedora, RHEL
sudo zypper install ./voktora-1.1.5-1.x86_64.rpm   # openSUSE
voktora

# désinstaller
sudo dnf remove voktora      # ou : sudo zypper remove voktora

Arch et dérivées

Un PKGBUILD de référence est dans Installers/Arch installer/. Fichier : voktora-1.1.5-1-x86_64.pkg.tar.zst

arch — sh
wget https://github.com/yo-le-zz/Voktora/releases/latest/download/voktora-1.1.5-1-x86_64.pkg.tar.zst
sudo pacman -U ./voktora-1.1.5-1-x86_64.pkg.tar.zst

Windows 10 / 11

Double-clic, puis l'assistant (Suivant, Installer, Terminer). Installé dans C:\Program Files\Voktora\. Fichier : Voktora_1.1.5_x64.msi

windows
# Télécharger puis double-cliquer
https://github.com/yo-le-zz/Voktora/releases/latest/download/Voktora_1.1.5_x64.msi

Le .msi n'est pas signé numériquement (pas de certificat de signature de code) : Windows peut indiquer « éditeur non reconnu ». Le code source est public ; téléchargez uniquement depuis les releases GitHub officielles.

macOS (Intel)

Pour les Mac à processeur Intel (x86_64). Il n'existe pas de version Apple Silicon (arm64). Ouvrez le .dmg et glissez Voktora dans Applications. Fichier : Voktora_1.1.5_x86_64.dmg

macOS — terminal
curl -LO https://github.com/yo-le-zz/Voktora/releases/latest/download/Voktora_1.1.5_x86_64.dmg

L'application n'est pas signée ni notarisée par Apple : au premier lancement, clic droit sur Voktora, puis Ouvrir. Ce build n'a pas encore été testé sur un vrai Mac.

Depuis les sources

Fonctionne aussi sur macOS (pas de paquet macOS). Extension Rust optionnelle (cargo). Fichier : —

sources — sh
git clone https://github.com/yo-le-zz/Voktora.git
cd Voktora
curl -LsSf https://astral.sh/uv/install.sh | sh   # une seule fois
uv sync
uv run python voktora/main.py

Vérifier le téléchargement

Chaque release publie un fichier SHA256SUMS contenant la somme SHA-256 de chaque fichier. Téléchargez-le dans le même dossier que votre paquet, puis :

sh
sha256sum -c SHA256SUMS --ignore-missing

La commande doit afficher OK pour votre fichier. Sous Windows, calculez la somme du .msi avec l'outil de votre choix et comparez-la à la ligne correspondante de SHA256SUMS. Aucune somme n'est recopiée ici : seule celle de la release fait foi.

Prérequis

  • Linuxpaquets .deb / .rpm / .pkg.tar.zst, dépendances Qt installées avec le paquet (OpenGL, GLib, bibliothèques XCB)
  • WindowsWindows 10 ou 11, x64
  • SourcesPython 3.13, uv ; Rust (cargo) optionnel pour l'extension native

Mise à jour automatique

Voktora consulte les versions GitHub au plus une fois par 24 h. Si une version plus récente existe, il propose de télécharger le fichier adapté à votre système. Le fichier doit avoir une somme SHA-256 publiée, sinon il est refusé. Voktora peut ensuite l'installer en arrière-plan, puis se relancer ; en cas d'échec, l'ancienne version est relancée. Préférences, « Rechercher une mise à jour… » pour vérifier à la main ; la vérification automatique se désactive avec updates.check = false. Détails.

Le script de mise à jour Windows n'a pas été testé sous Windows.
