Voktora 1.1.3

Gestionnaire de projets de développement pour le bureau (Linux, Windows).

Télécharger Documentation Code source

À propos

Voktora range vos projets au même endroit : dossiers et dépôts Git, profils d'exécution, hooks, snapshots, vault chiffré pour les secrets. Une application Qt locale, sans compte ni serveur. Les plugins (Python, JavaScript ou Rust) et les boutiques de thèmes, d'icônes et de styles permettent de l'adapter.

Installer

Debian, Ubuntu, Mint 
wget https://github.com/yo-le-zz/Voktora/releases/latest/download/voktora_1.1.3_amd64.deb
sudo apt install ./voktora_1.1.3_amd64.deb
Fedora, RHEL, openSUSE 
wget https://github.com/yo-le-zz/Voktora/releases/latest/download/voktora-1.1.3-1.x86_64.rpm
sudo dnf install ./voktora-1.1.3-1.x86_64.rpm
Arch, Manjaro, EndeavourOS 
wget https://github.com/yo-le-zz/Voktora/releases/latest/download/voktora-1.1.3-1-x86_64.pkg.tar.zst
sudo pacman -U ./voktora-1.1.3-1-x86_64.pkg.tar.zst
Windows 10 / 11 
Téléchargez Voktora_1.1.3_x64.msi dans les releases puis double-cliquez dessus.
Adresse : https://github.com/yo-le-zz/Voktora/releases/latest/download/Voktora_1.1.3_x64.msi
Depuis les sources 
git clone https://github.com/yo-le-zz/Voktora
cd Voktora
uv sync
uv run python voktora/main.py

Lancement : voktora. Chaque release publie un fichier SHA256SUMS. Le .msi n'est pas signé : Windows peut afficher un avertissement.

Fonctions

  • Projets, groupes, recherche, statuts et catégories
  • Git intégré, clonage de dépôts, GitHub
  • Vault chiffré et chiffrement de fichiers
  • Snapshots, synchronisation entre deux ordinateurs
  • Plugins officiels : Code Inspector, DevOps Center, API Studio, Project Knowledge, Workflow Forge, et d'autres
  • Mise à jour assistée : téléchargement vérifié (SHA-256), installation en arrière-plan

Développeurs

Écrire un plugin : doc/plugins. Thèmes, icônes et styles : doc/SHOPS.md.
