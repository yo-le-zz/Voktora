Vos projets de développement, au même endroit.

Gestionnaire de projets avec interface Qt : dépôts Git, profils de lancement, hooks, coffre de secrets, snapshots. Local, sans compte, libre (MIT).

Installer

Choisissez votre système.

Linux

Debian, Ubuntu, Mint

deb — sh
wget https://github.com/yo-le-zz/Voktora/releases/latest/download/voktora_1.1.6_amd64.deb
sudo apt install ./voktora_1.1.6_amd64.deb
voktora

Le paquet résout aussi les dépendances.

Fedora, openSUSE

rpm — sh
wget https://github.com/yo-le-zz/Voktora/releases/latest/download/voktora-1.1.6-1.x86_64.rpm
sudo dnf install ./voktora-1.1.6-1.x86_64.rpm        # Fedora, RHEL
sudo zypper install ./voktora-1.1.6-1.x86_64.rpm     # openSUSE
voktora

Les bibliothèques Qt nécessaires sont résolues automatiquement.

Arch, Manjaro, EndeavourOS

arch — sh
wget https://github.com/yo-le-zz/Voktora/releases/latest/download/voktora-1.1.6-1-x86_64.pkg.tar.zst
sudo pacman -U ./voktora-1.1.6-1-x86_64.pkg.tar.zst
voktora

Un PKGBUILD de référence (voktora-bin) est fourni dans le dépôt.

Windows 10 / 11 (x64)

windows — msi
# Télécharger le .msi, puis double-cliquer dessus
https://github.com/yo-le-zz/Voktora/releases/latest/download/Voktora_1.1.6_x64.msi

Le .msi n'est pas signé : Windows peut afficher un avertissement SmartScreen. N'utilisez que les releases GitHub officielles. Télécharger le .msi.

Depuis les sources

sources — sh
git clone https://github.com/yo-le-zz/Voktora.git
cd Voktora
curl -LsSf https://astral.sh/uv/install.sh | sh   # uv, une seule fois
uv sync
uv run python voktora/main.py

Aussi pour macOS : il n'existe pas de paquet, seulement l'installation depuis les sources. Python 3.13 et uv requis.

Premier lancement

Voktora demande un mot de passe maître : il n'est jamais stocké (seul un vérificateur PBKDF2 est conservé) et protège le coffre. Vous pouvez le passer, mais ce n'est pas conseillé. Les données sont dans ~/.voktora/ ; elles ne sont pas supprimées à la désinstallation.

Fonctions

  • ProjetsDépôts Git classés par catégories, vue liste ou grille, import et clonage.
  • Profils et hooksCommande, variables et scripts par projet ; hooks sur 7 événements Git.
  • CoffreTokens, clés SSH et clés d'API chiffrés, mot de passe maître jamais stocké.
  • SnapshotsCapture, comparaison et restauration de l'état d'un projet.
  • SynchronisationEntre deux PC du même réseau, chiffrée, avec reprise automatique.
  • PluginsPython, JavaScript ou Rust, installables depuis le marketplace.
  • ApparenceThèmes, packs d'icônes et styles installables.
  • Mise à jourTéléchargement vérifié par SHA-256, installation en arrière-plan.
